Options, as pitched

A separate tutorial.html with the same bench markup and the same app.jsRecommended

pick A

The lessons sit beside the one editor, so a lesson can load a deck and press Run in place. One app.js means one set of card-column rules, which is the reason the roadmap gives for refusing a second editor. Cost: a second copy of about 100 lines of bench markup, plus a test that keeps the two copies the same. app.js also needs changes to start on either page, because today it fails on a page with no build stamp. Easy to undo.

Tutorial sections around the bench on the front page

pick B

No second copy of the markup. But Jack asked for a separate tutorial page, so this goes against his own request. The front page exists to bring a reader in, and web-copy rule A4 limits its paragraphs to three sentences. Eleven lessons would bury the compiler. Moving them out later means rewriting the page.

A text-only tutorial page; each example is a share link that opens the front page with that deck

pick C

Cheapest: no editor code, and share links already exist. The reader goes back and forth between two pages and loses 'change a line, run, see the report change' on one screen. It goes against the roadmap's 'the tutorial page, with the W1 editor', so that entry would need an edit.

Scope alternative: a language course of many small programs instead of one walk through the sample

pick S2

Teaches more of COMTRAN. But any example that reads input needs its own input tapes built into the site. Each example also needs a test that keeps it compiling, or the tutorial breaks silently when the compiler changes. The writing and test cost is several times that of the walk through the sample.

Recommendation, as pitched

A is the only form that puts the lesson and the running program on one screen with one editor. Its one cost, a second copy of the markup, is caught by a cheap test. Keep the scope to one walk through the sample. Every lesson that uses the unedited sample can then be tied to the existing 90.05 goldens. That includes the defect-10 lesson: RET.PREM is read as INS.PREM (M6-4 finding 1). Lesson 8, where the reader edits a line, needs a test of its own.
