# F28-8043: General Information Manual — IBM Commercial Translator

IBM, June 1960. Scanned source: [`F28-8043_CommercialTranslatorGenInfMan_Ju60.pdf`](F28-8043_CommercialTranslatorGenInfMan_Ju60.pdf) in this directory (124 PDF pages).

This is the language-level introduction to the Commercial Translator (COMTRAN):
language structure, procedure statements, data description, and a complete worked
payroll example.

## Conventions used in the conversion

- Every source page is marked in the text as `**[page N]**` with an HTML comment
  giving the PDF page: `<!-- page N | PDF M -->`. Cite by printed page number.
- Full-page scans of every page are in [`images/`](images/) as `page-NNN.png`
  (NNN = zero-padded PDF page number).
- Figures, flowcharts, and coding-form facsimiles are embedded as page images at
  the point they occur; program text on forms is additionally transcribed in
  fenced code blocks where legible.
