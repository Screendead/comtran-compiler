# J28-6169-1: IBM 709/7090 Commercial Translator Processor — Preliminary Reference Manual

IBM, January 1962 (revision 2; some pages dated 10/61). Scanned source:
[`J28-6169-1_CommercialTranslator_Jan62.pdf`](J28-6169-1_CommercialTranslator_Jan62.pdf)
in this directory (221 PDF pages).

This is the processor (implementation) reference for the 709/7090 Commercial
Translator: compiler behaviour and the definitive statement/data/environment
reference (Section 02), plus loader, monitor, operating and maintenance
procedures, and appendices covering generated code, object format, error
messages, and a complete compiled sample program.

## Conventions used in the conversion

- This manual has no ordinary page numbers: each page carries a section code
  (top-right header) like `02.05.05`. Pages are marked in the text as
  `**[02.05.05]**` with an HTML comment giving the PDF page:
  `<!-- 02.05.05 | PDF 100 -->`. Cite by section code.
- Full-page scans of every page are in [`images/`](images/) as `page-NNN.png`
  (NNN = zero-padded PDF page number).
- Appendix 90.05 consists of landscape line-printer listings; these are embedded
  as page images, with source-program listings additionally transcribed in fenced
  code blocks.
- Overpunched digits are rendered by zone: minus-zone (an overbar in print)
  with a combining overline, e.g. `9̅`; plus-zone (a raised plus in print)
  with a superscript plus, e.g. `9⁺`.
